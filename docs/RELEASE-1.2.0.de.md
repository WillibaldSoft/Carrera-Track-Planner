# Version 1.2.0 – Updateprüfung und gesicherte Installation

Updatefenster im Startbildschirm und Vollbild-Editor. Prüfung beim Start optional und standardmäßig aus. Installation nur nach Klick, mit Download-/Datei-Prüfsummen, geprüfter Sicherung, Neustart und automatischem Rückfall bei Startfehlern. Offene ungespeicherte Änderungen sperren die Installation. Beschreibbare eigenständige Installationen werden unterstützt; Debian-Systempakete und das RaceHubOS-Add-on behalten ihren manuellen Installationsweg. Die AGPL-Lizenz und sichtbaren Quellverweise bleiben erhalten.
