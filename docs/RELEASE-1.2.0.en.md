# Version 1.2.0 – Update checks and backed-up installation

Update panel on the start screen and fullscreen editor. Startup checks are optional and off by default. Installation requires a click, verifies download/file checksums, creates a verified backup and restarts with automatic rollback on startup failure. Unsaved edits block installation. Writable standalone installations are supported; Debian system packages and the RaceHubOS add-on keep manual installation paths. AGPL licensing and visible source links are preserved.
