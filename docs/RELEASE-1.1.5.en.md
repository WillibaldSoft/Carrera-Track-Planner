# Version 1.1.5 – Hide overlapping layers

**Visible layer** in the central toolbar controls visibility only: choose one layer or **All layers** for the complete track. This is separate from the existing **Drawing layer → Bring forward / Send backward** controls that change the stacking order of rails and shoulders.

Visibility follows the assigned track level plus its drawing offset. Independently lowered shoulders and pit pieces appear on their own drawing planes. Heights and stacking order remain unchanged; the visibility choice is a temporary editor view.

Switching layers clears selections, endpoint choices and previews. Hidden rails have no clickable connection handles or elevation labels. Select all and box selection include only visible, editable rails. New rails use the chosen layer. Assemblies spanning multiple layers must first be ungrouped in the full view to avoid moving hidden rails inadvertently.
