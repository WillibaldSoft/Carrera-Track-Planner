# Version 1.1.5 – Masquer les calques superposés

**Calque visible** dans la barre centrale règle uniquement la visibilité : choisir un calque ou **Tous les calques** pour afficher le circuit entier. Cette commande est distincte de **Calque de dessin → Avancer / Reculer**, qui modifie l’ordre des rails et bordures.

La visibilité utilise le niveau attribué au rail et son décalage de dessin. Les bordures abaissées séparément et les éléments des stands apparaissent sur leur propre calque. Les hauteurs et l’ordre restent inchangés ; le choix d’affichage est temporaire.

Changer de calque efface les sélections, les extrémités choisies et les aperçus. Les rails masqués n’ont ni raccords cliquables ni étiquettes d’altitude. Tout sélectionner et la sélection rectangulaire concernent uniquement les rails visibles et modifiables. Les nouveaux rails utilisent le calque choisi. Dissocier d’abord dans la vue complète les assemblages répartis sur plusieurs calques pour éviter de déplacer des rails masqués.
