# Version 1.1.4 – Bordures avec les nouveaux rails

Activer **Poser les bordures avec les nouveaux rails** dans le catalogue gauche, puis choisir **Gauche**, **Droite** ou **Des deux côtés**. Le choix reste actif lors des changements de pièce et des poses répétées. L’insertion avant/après la sélection, le glisser-déposer et la première pose sur un plan vide l’utilisent également. L’aperçu inclut les bordures ; une annulation retire ensemble rail et bordures. Les rails existants gardent leurs réglages. Les côtés bloqués, notamment par le boîtier CU, sont ignorés.

Pour les stands, sélectionner une pièce individuelle, ouvrir **Bordures** dans le catalogue et ajouter la bordure proposée. Les entrées/sorties utilisent les formes extérieures 20602 ; les droites à une voie et de ravitaillement utilisent les bordures droites 20560 de chaque côté. Les raccords occupés ne sont plus proposés. Le plan natif conserve ces pièces pour l’inventaire, la 2D/3D et l’export. Les bordures exactement raccordées suivent les coordonnées, la rotation et le changement de support de la pièce des stands. Les bordures déplacées séparément restent indépendantes.
