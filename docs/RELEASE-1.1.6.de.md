# Version 1.1.6 – Ebenen unabhängig per Checkbox

Die zentrale Schaltfläche **Ebenen** öffnet eine kompakte Auswahl mit einer Checkbox pro Ebene. Jede Kombination ist möglich: beispielsweise Ebene 0 und 2 gemeinsam einblenden und Ebene 1 ausblenden. Alle eingeblendeten Schienen bleiben gleichzeitig auswählbar und bearbeitbar.

- **Alle anzeigen** stellt die vollständige Ansicht wieder her; **Alle ausblenden** zeigt einen Hinweis und verhindert das unsichtbare Neulegen von Schienen.
- **Nur diese** isoliert eine Ebene mit einem Klick.
- Bei mehreren eingeblendeten Ebenen legt **Neue Schienen auf Ebene** das Ziel für neu angelegte Schienen fest. Bei eingeschränkter Ebenenauswahl übernimmt eine angeklickte Schiene ihre Ebene als Vorgabe.
- Markierungen auf weiterhin sichtbaren Ebenen bleiben erhalten. Versteckte Markierungen werden entfernt; Baugruppen mit versteckten Mitgliedern werden als Ganzes abgewählt. Sind alle Ebenen einer Baugruppe sichtbar, bleibt sie gemeinsam bearbeitbar.
- Checkboxen, Schnellaktionen, Zielauswahl und Hilfe liegen zusammen. Die Auswahl bleibt beim Ankreuzen geöffnet, schließt mit Escape oder einem Klick außerhalb und wird auch auf schmalen Bildschirmen nicht von der Werkzeugleiste abgeschnitten.

Zeichenreihenfolge, Höhenprofile und gespeicherte Pläne bleiben unverändert. Randstreifen, Boxenteile, Anschlüsse und Höhenbeschriftungen folgen der sichtbaren Ebenenauswahl.
